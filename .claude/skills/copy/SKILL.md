# Copy — tom do projeto

Projeto de instituição beneficente cristã. Regras:
1. Tom acolhedor, caloroso, direto. Trate o leitor com respeito.
2. PROIBIDO: palavrão, gíria pesada, duplo sentido, sarcasmo agressivo, jargão de startup ("supercharge", "unleash", "revolucione").
3. Sem referência religiosa explícita no produto (nada de versículos, símbolos ou vocabulário litúrgico).
4. Português claro; frases curtas; sem caps lock de urgência falsa.
5. Emails transacionais: cumprimento pelo nome, uma ação clara, despedida simples.
